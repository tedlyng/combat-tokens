COMBAT TOKENS 1.4.0: UPDATING
=============================

Takes about 10 minutes. Tokens, templates and player assignments are all kept.
New in 1.4.0: the Béthorm bestiary is built in (the new file bestiary.json).

The new address for Owlbear is:
    https://tedlyng.github.io/combat-tokens/manifest-1-4-0.json


1. UNZIP
   Double-click combat-tokens.zip in Downloads and open the new folder.
   Upload everything EXCEPT the "source" folder: 20 files.

2. UPLOAD TO GITHUB
   - Go to https://github.com/tedlyng/combat-tokens
   - Add file > Upload files.
   - In Finder: Cmd+A, then Cmd-click "source" to un-select it. Drag the files in.
   - Wait for all names to appear, then click the green "Commit changes".

3. WAIT FOR GITHUB (1-3 minutes)
   - Actions tab: wait for a green tick on "pages build and deployment".
   - Open https://tedlyng.github.io/combat-tokens/manifest-1-4-0.json
     It should say "version": "1.4.0". If "404", wait a minute and refresh.

4. REPLACE THE EXTENSION IN OWLBEAR
   - Profile > My Extensions: remove every "Combat Tokens" entry.
   - Add an extension with exactly:
       https://tedlyng.github.io/combat-tokens/manifest-1-4-0.json
   - Check it shows 1.4.0.

5. TURN IT ON IN YOUR ROOM
   - Switch Combat Tokens on in the room's extension settings.
   - Cmd+Shift+R to reload. The panel's bottom corner must say v1.4.0.
   - Players: reload too (Cmd+Shift+R / Ctrl+Shift+R).

6. TRY IT
   - Drop any monster token on the map and rename it "Ahoggya, Medium/Soldier".
     Its rings and badges should appear at once (HP 14, Def 1, Armor 3).
   - Or right-click a token > Combat stats > Bestiary box: type, pick, Load.

IF SOMETHING GOES WRONG
- Panel blank or old version: reload with Cmd+Shift+R; check step 3; redo step 4.
- Players' changes or damage not applied: the GM must be in the room.
